## 📁 ملخص منظم للملفات الثلاثة (FinGuard AI)

---

### 1. `FinGuardAIChat.tsx` – واجهة المحادثة الذكية

**الهدف:** توفير مساعد دردشة تفاعلي (AI Chatbot) للإجابة على استفسارات المستخدمين حول السياسات المالية والتدقيق.

**المكونات والوظائف الرئيسية:**

- **واجهة محادثة كاملة (RTL)** مع عرض رسائل المستخدم والردود الآلية.
- **حالة المحادثة:** تخزين الرسائل (`messages`)، حالة الكتابة (`isTyping`)، حالة الإرسال (`isSending`).
- **تمرير تلقائي** إلى آخر رسالة عند الإضافة أو عند ظهور مؤشر الكتابة.
- **محاكاة استجابة الذكاء الاصطناعي** بناءً على كلمات مفتاحية (سياسة، قانون، طلب، اعتماد، شكر) مع ردود افتراضية.
- **محاكاة تأخير الشبكة** (800-1500 مللي) لعرض مؤشر الكتابة.
- **إرسال الرسائل** عبر زر الإرسال أو الضغط على `Enter`.
- **زر إرفاق ملف** (وهمي) مع تنبيه توضيحي.
- **زر المنزل** للتمرير إلى أعلى الصفحة.
- **تصميم متجاوب** مع خلفية متدرجة، فقاعات رسائل مميزة (user-bubble / ai-bubble)، ومؤشر كتابة بنقاط متحركة.
- **إشارات مرئية** لحالة RAG النشط والتدقيق الفوري.

**التقنيات المستخدمة:** React hooks (`useState`, `useEffect`, `useRef`), TypeScript, Tailwind CSS.

### 2. `FinancialRequestsDashboard.tsx` – لوحة إدارة الطلبات المالية

**الهدف:** عرض وإدارة جميع طلبات الصرف المالية مع تدقيق RAG فوري وإجراءات جماعية وفردية.

**المكونات والوظائف الرئيسية:**

- **عرض بيانات الطلبات** في جدول تفاعلي يحتوي على 12 طلبًا نموذجيًا (محاكاة API).
- **بطاقات إحصائية** تعرض: إجمالي الطلبات، إجمالي المبالغ، عدد الطلبات قيد المراجعة، عدد المخالفات.
- **فلترة متقدمة**:
  - حسب الحالة (متوافق / مخالف / مراجعة)
  - حسب مستوى المخاطر (منخفض / متوسط / عالي)
  - بحث نصي في رقم الطلب، الموظف، القسم، الغرض
- **زر مسح جميع الفلاتر**.
- **إجراءات جماعية**:
  - تحديد طلبات متعددة عبر checkbox على مستوى الصف أو تحديد الكل.
  - موافقة جماعية (محاكاة) مع إشعار بعدد الطلبات.
- **تصدير البيانات المفلترة إلى ملف CSV** مع دعم اللغة العربية (BOM).
- **إجراءات فردية** لكل طلب (عرض، تعديل، موافقة سريعة، إخطار الامتثال) مع تنبيهات توضيحية.
- **تمييز بصري** للحالة (ألوان وأيقونات) والمخاطر (أشرطة ملونة).
- **تذييل الجدول** يعرض عدد النتائج ونظام التدقيق (RAG v3).

**التقنيات المستخدمة:** React (`useState`, `useCallback`, `useMemo`), TypeScript, Tailwind CSS, CSV export.

### 3. `FinGuardAIAnalyzer.tsx` – أداة تحليل الطلبات المالية بالذكاء الاصطناعي (RAG)

**الهدف:** تمكين المستخدم من إدخال بيانات طلب مالي (الموظف، الغرض، المبلغ) وتحليله فورياً باستخدام محرك RAG (Retrieval-Augmented Generation) محاكى مع اقتباسات من سياسات الشركة.

**المكونات والوظائف الرئيسية:**

- **قاعدة سياسات مدمجة (محاكاة RAG)** تحتوي على 5 سياسات:
  - المشتريات التقنية (حد 3000$)
  - مكافحة غسيل الأموال (حد 2500$)
  - السفر والإقامة (حد 4000$)
  - المصروفات الإدارية (حد 1500$)
  - التسويق والفعاليات (حد 5000$)
- **دالة تحليل ذكية** (`analyzeRequest`) تبحث عن سياسة تطابق كلمات مفتاحية في الغرض، ثم تقارن المبلغ بالحد المسموح، وتعيد نتيجة من نوع `AnalysisResult` تحتوي على:
  - الحالة (متوافق / مخالف / مراجعة)
  - القرار النصي
  - التبرير
  - عنوان السياسة المقتبسة
  - نص الاقتباس
  - الحد المسموح (إن وجد)
- **واجهة إدخال** تحتوي على ثلاثة حقول (الموظف، الغرض، المبلغ) مع دعم الإرسال بزر Enter.
- **عرض النتيجة** في ثلاث بطاقات منفصلة:
  - البند المقترح + اقتباس السياسة
  - التوصية (مع أيقونة حسب الحالة)
  - التبرير + معلومات الحد
- **تأثيرات بصرية**:
  - حدود ملونة حسب الحالة (أخضر / أحمر / أصفر)
  - ظل متناسق مع الحالة
  - اهتزاز (shake) عند ظهور نتيجة "مخالف"
- **تحليل تلقائي تجريبي** عند تحميل الصفحة (باستخدام `useEffect`).
- **زر طلب مالي جديد** (تنبيه توضيحي).
- **زر دردشة عائم** (تنبيه تجريبي).
- **تصميم متجاوب** مع أنماط مخصصة (input-modern، inner-rect-card، shake-border).

**التقنيات المستخدمة:** React (`useState`, `useRef`, `useEffect`), TypeScript, Tailwind CSS, CSS animations.

## ✅ خلاصة عامة

| الملف | الوظيفة الأساسية | المخرجات الرئيسية |
|-------|----------------|------------------|
| `FinGuardAIChat.tsx` | محادثة تفاعلية (AI Chatbot) | أسئلة وأجوبة حول السياسات المالية |
| `FinancialRequestsDashboard.tsx` | لوحة إدارة الطلبات | جدول + فلاتر + إحصائيات + تصدير + إجراءات جماعية |
| `FinGuardAIAnalyzer.tsx` | أداة تحليل RAG للطلبات | تقييم فوري مع اقتباسات من السياسات |
